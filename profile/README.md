# 📊 Profile Stats

This folder contains auto-generated SVG files for the GitHub profile README.

## Files

| File | Description | Generated By |
|------|-------------|--------------|
| `stats.svg` | GitHub statistics card | [github-readme-stats](https://github.com/anuraghazra/github-readme-stats) |
| `top-langs.svg` | Most used languages | [github-readme-stats](https://github.com/anuraghazra/github-readme-stats) |
| `github-contribution-grid-snake.svg` | Contribution snake animation | [platane/snk](https://github.com/platane/snk) |
| `github-contribution-grid-snake-dark.svg` | Dark theme snake animation | [platane/snk](https://github.com/platane/snk) |

## Auto-Update

These files are automatically updated **daily** via GitHub Actions workflow:
`.github/workflows/generate-profile-stats.yml`

## Manual Update

To manually trigger the workflow:
1. Go to **Actions** tab in your repository
2. Click **Generate Profile Stats**
3. Click **Run workflow**
